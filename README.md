# Contract Assistant Downloads

Public installer downloads for two Microsoft Word add-ins:

- **Contract Assistant v1.8.4** — clause review, drafting optimization, tracked revisions, and source-language comments.
- **Full Contract Review v1.0.0** — one-click whole-contract review with batch tracked revisions and source-language comments.

## Download

Open the [latest GitHub Release](https://github.com/losteye/contract-assistant-downloads/releases/latest) and choose the ZIP for your operating system.

### Windows

Download the corresponding Windows ZIP, choose **Extract All**, then double-click the included `Install-*.cmd` file.

### macOS

Download the corresponding macOS ZIP, extract it, then double-click `install-mac.command`. If macOS blocks it, right-click the file in Finder and choose **Open**.

The installers connect to `https://contract.joel.best` and contain no API keys.

AI-assisted contract review is not a substitute for legal advice.
